1. प्रोजेक्ट परिचय एवं उद्देश्य (EXECUTIVE OVERVIEW)
--------------------------------------------------------------------------------
"Hindi Anime Guide" भारत का पहला संपूर्ण, हाई-परफॉर्मेंस और कानूनी एनीमे पोर्टल है।
इसका मुख्य उद्देश्य भारतीय एनीमे प्रशंसकों को यह सटीक जानकारी देना है कि उनका 
पसंदीदा एनीमे भारत में किस आधिकारिक प्लेटफॉर्म (Netflix, Crunchyroll, JioHotstar,
Prime Video) पर उपलब्ध है, उसमें हिंदी डबिंग या सबटाइटल्स हैं या नहीं, और आगामी एपिसोड 
कब प्रसारित होंगे।

पोर्टल पूरी तरह द्विभाषी (Bilingual: हिंदी एवं अंग्रेज़ी) है, जो एक-क्लिक में 
सहजता से भाषा बदलता है और भारतीय यूज़र्स के लिए फ़ास्ट, मॉडर्न और टच-फ़्रेंडली है।


2. तकनीकी ढांचा (FULL TECH STACK)
--------------------------------------------------------------------------------
- बैकएंड फ्रेमवर्क:    FastAPI + Uvicorn + Starlette (Asynchronous Python 3.11+)
- डेटाबेस ओआरएम:      SQLModel 0.0.14 + SQLAlchemy 2.0 (Modern Type-Safe ORM)
- डेटाबेस (प्रोडक्शन): Neon Serverless PostgreSQL (PgBouncer Pooled Connection)
- डेटाबेस (लोकल/टेस्ट): SQLite 3 (WAL Journal Mode + Foreign Key PRAGMA)
- माइग्रेशन इंजन:     Alembic (Head Revisions Auto-migrated on startup)
- फ्रंटएंड व्यू इंजन:   Jinja2 Server-Side Rendering (SSR) + Reusable Macros
- सीएसएस / स्टाइलिंग:  Tailwind CSS JIT CDN + Custom CSS Tokens (tokens.css)
- रिएक्टिव यूआई:      Alpine.js (Tabs, Accordions, Countdown, Modals, Bookmarks)
- आइकॉन्स व टाइपोग्राफी: Font Awesome 6.4 + Self-hosted Noto Serif Devanagari Variable
- इमेज प्रोसेसिंग:     Pillow (PIL) — 16:9 widescreen crop, LANCZOS, WebP (quality=90)
- सुरक्षा व ऑथ:       JWT HttpOnly Cookies, TOTP 2FA (RFC 6238), CSRF Tokens, Google OAuth 2.0
- एआई ऑटोमेशन:        Google Gemini API (gemini-2.5-flash & gemini-1.5-flash fallback)
- क्लाउड होस्टिंग:     Render Cloud Containers + GitHub Actions CI/CD Pipeline


3. डिज़ाइन सिस्टम व यूएक्स (DESIGN SYSTEM & THEMING)
--------------------------------------------------------------------------------
- डिफ़ॉल्ट थीम: डार्क थीम (Pure Black `#0a0a0a`, Charcoal `#121212`, Card `#141414`)
- एक्सेंट कलर: वाइब्रेंट रेड / क्रिमसन (`#dc2626` / `#ef4444`)
- हेडिंग्स: थ्री-कलर ग्रेडिएंट टेक्स्ट (व्हाइट -> लाइट ग्रे -> सॉफ्ट रेड)
- कार्ड्स: 3D Parallax Tilt इफेक्ट्स, ग्लासमोर्फिक नियॉन बैज, 16:9 आस्पेक्ट रेशियो कवर्स
- टाइपोग्राफी: "Noto Serif Devanagari" (हिंदी के लिए साफ़ और पठनीय) + "Noto Serif" / "Bell MT"


4. प्रमुख पृष्ठ व यूआई फ़ीचर्स (PAGES & USER CAPABILITIES)
--------------------------------------------------------------------------------
1. होमपेज (/) :
   - डायनामिक सर्च बार, क्विक फ़िल्टर्स, हीरो स्पॉटलाइट आर्टिकल
   - "ताज़ा अपडेट्स" (Latest Updates) ग्रिड (समाचार, शेड्यूल, मंगा, अवॉर्ड्स)
   - "ताज़ा एनीमे गाइड्स" (Latest Anime Guides) 5-कॉलम डेस्कटॉप ग्रिड
   - ओटीटी प्लेटफॉर्म नियॉन बैज (NF, CR, Hotstar, Prime) और हिंदी डब बैज

2. एक्सप्लोर एवं फ़िल्टर (/explore) :
   - लाइव सर्च (शीर्षक, श्रेणी, सामग्री में खोज)
   - बहु-स्तरीय फ़िल्टरिंग: ओटीटी प्लेटफॉर्म, हिंदी डब (हाँ/नहीं), 13 श्रेणियां, सॉर्टिंग

3. आर्टिकल डिटेल पेज (/article/{slug}) :
   - संपूर्ण संपादकीय गाइड, आधिकारिक स्ट्रीमिंग उपलब्धता तालिका
   - लास्ट चेक्ड (सत्यापित) समय, पठन समय, बुकमार्क बटन (Alpine.js)
   - यूज़र कमेंट्री सिस्टम (प्रतिक्रियाएं व विलोपन)
   - "जानकारी रिपोर्ट करें" (Outdated Info Report Modal) सुरक्षित सीएसआरएफ के साथ
   - संबंधित लेख (Related Guides) सिफ़ारिशें

4. अपडेट्स हब (/updates) :
   - 5 समर्पित अनुभाग: समाचार, आज का प्रसारण, मंगा चैप्टर्स, अवॉर्ड्स, ट्रेलर्स
   - प्रत्येक अनुभाग में 4 शीर्ष आइटम और "सभी देखें" डायरेक्ट लिंक

5. सीज़न प्रसारण शेड्यूल (/schedule) :
   - सोमवार से रविवार दैनिक टैब्स (भारतीय समयानुसार ऑटो-ओपन टुडे)
   - लाइव अल्पाइन काउंटडाउन टाइमर (अगले एपिसोड के लिए सेकंड-दर-सेकंड उलटी गिनती)
   - एयरिंग टाइम इन IST, हिंदी डब फ़िल्टर, सीज़न फ़िल्टर

6. एनीमे समाचार (/news) :
   - प्रमुख फीचर्ड स्टोरी हीरो कार्ड, 2-कॉलम/3-कॉलम ग्रिड, श्रेणी चिप्स, पेजिनेशन

7. मंगा अपडेट्स (/manga) :
   - डेस्कटॉप पर साफ़-सुथरी कॉम्पैक्ट टेबल और मोबाइल पर स्टैक्ड कार्ड्स
   - लेटेस्ट चैप्टर नंबर, रिलीज़ तिथि, स्टेटस (Ongoing/Completed/Hiatus), रीडर लिंक

8. एनीमे अवॉर्ड्स (/awards) :
   - वर्ष चयनकर्ता (2024, 2025, 2026)
   - ग्रैंड प्राइज विनर (Anime of the Year) हाइलाइटेड गोल्डन कार्ड
   - नामांकित टाइटल्स (Nominees) ग्रिड

9. आधिकारिक ट्रेलर्स (/trailers) :
   - क्लिक-टू-प्ले लेज़ी यूट्यूब एम्बेड्स (पहले पोस्टर लोड होता है, क्लिक पर ही यूट्यूब लोड होता है जिससे डेटा और स्पीड की 100% बचत होती है)

10. यूज़र प्रोफाइल व सुरक्षा (/auth/*) :
    - ईमेल ओटीपी पंजीकरण व लॉगिन, गूगल 2-क्लिक OAuth
    - प्रोफ़ाइल अवतार अपलोड, खाता सेटिंग्स, सहेजे गए गाइड्स (Bookmarks)
    - टू-फ़ैक्टर ऑथेंटिकेशन (TOTP QR कोड, 10 रिकवरी बैकअप कोड्स, 30 दिन डिवाइस ट्रस्ट)

11. एडमिन पोर्टल (/admin/*) :
    - डैशबोर्ड मेट्रिक्स व ग्राफ़्स, आर्टिकल राइटिंग व मार्कडाउन लाइव प्रीव्यू
    - ऑटोमेशन ड्राफ़्ट्स सूची व 1-क्लिक पब्लिश, यूज़र बैन/एक्टिवेट, कमेंट मॉडरेशन


5. ऑटोमेशन पाइपलाइन आर्किटेक्चर (AI ENGINE & CRON)
--------------------------------------------------------------------------------
- सोर्सेज (automation/): AniList GraphQL API, LiveChart RSS, MangaDex API
- एआई रीराइटर (automation/rewriter.py): 
  Google Gemini API का उपयोग करके केवल प्रामाणिक तथ्यों पर आधारित मूल हिंदी व 
  अंग्रेज़ी संपादकीय तैयार करता है। टाइमआउट या कोटा समाप्त होने पर ऑफ़लाइन फ़ॉलबैक।
- शेड्यूलर (.github/workflows/fetch.yml):
  GitHub Actions पर हर 3 घंटे (0 */3 * * *) में पूरी तरह स्वचालित रन।

2. इमेज 404 और हॉटलिंकिंग/आईएसपी ब्लॉक समाधान:
   - सभी कवर्स को लोकली डाउनलोड करके 16:9 वाइडस्क्रीन WebP में कन्वर्ट किया गया
     और गिटहब के ज़रिए लाइव सर्वर पर पब्लिश किया गया।
   - सभी 11 टेम्प्लेट्स में `referrerpolicy="no-referrer"` और `onerror` फ़ॉलबैक लगाया गया।
   - लाइव वेबसाइट पर होमपेज के सभी 18/18 कवर्स HTTP 200 OK सत्यापित।

3. Neon PostgreSQL कनेक्शन पूल अनुकूलन:
   - `app/db.py` में `pool_size=5, max_overflow=5` सेट किया गया ताकि Neon सर्वरलेस 
     के 20-कनेक्शन लिमिट के भीतर सिस्टम बिना किसी 'Connection Exhaustion' के स्थिर रहे।

4. साइडबार लैंग्वेज टॉगल का SSR समाधान:
   - Jinja2 सर्वर-साइड रेंडरिंग में `SIDEBAR_TITLES_EN` मैपिंग जोड़ी गई जिससे अंग्रेज़ी 
     चुनने पर पेज रीफ़्रेश होने पर हिंदी का कोई भी फ्लैश (Flash of un-translated text) नहीं दिखता।

5. सुरक्षा व सीएसआरएफ (CSRF) सुधार:
   - `article.html` के रिपोर्ट मॉडल में सीएसआरएफ टोकन और स्पष्ट पोस्ट एक्शन लागू किया गया।
   - `AnimeDraft` टेबल पर `(status, published_at)` कम्पोजिट इंडेक्स जोड़ा गया।

6. Phase 1 - डेटा अखंडता एवं मॉडल अपग्रेड (13 नवंबर 2026):
   - `AnimeDraft` में 5 नए कॉलम्स (chapters, volumes, publication_status, airing_day, airing_time) जोड़े गए।
   - Alembic माइग्रेशन (f1a2b3c4d5e6) सफलता पूर्वक Neon PostgreSQL पर लागू किया गया।
   - मंगा पेजों से बनावटी मॉड्यूलो स्टेटस हटाया गया और AniList के वास्तविक डेटा (One Piece 1130+, JJK 272, CSM 182+, Solo Leveling 201) से सिंक किया गया।

   - 2026 के काल्पनिक अवॉर्ड्स अर्काइव किए गए, केवल 2024 के 100% सत्यापित विजेताओं को लाइव रखा गया।
